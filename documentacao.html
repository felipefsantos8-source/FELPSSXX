ESTRUTURA DO PROJETO

Esta página reúne a proposta de modelagem de dados e a documentação técnica do Omnitorrinco. O banco descrito é uma proposta para uma futura versão com persistência; atualmente, o site funciona como Front-End estático com base de conhecimento JSON.

1. Objetivo e escopo

O Omnitorrinco organiza informações sobre addons, texturas, mapas e ferramentas relacionadas ao Minecraft. A versão atual apresenta conteúdo informativo, galeria, formulário demonstrativo e chatbot com respostas carregadas de um arquivo JSON.

REGRA

Uma categoria pode possuir vários conteúdos.

Cada conteúdo pertence a uma categoria.

Cardinalidade: CATEGORIA 1:N CONTEUDO. A entidade MENSAGEM_CONTATO é independente no modelo inicial.

4. Restrições de domínio e negócio

  • O nome da categoria deve ser único.
  • Título, descrição e categoria do conteúdo são obrigatórios.
  • Todo conteúdo deve apontar para uma categoria existente.
  • O e-mail deve respeitar o formato esperado pela aplicação.
  • O assunto deve corresponder a uma opção válida do formulário.
  • O formulário atual é demonstrativo e não grava mensagens no banco.

5. Arquivos do projeto

  • index.html: estrutura e conteúdo principal.
  • style.css: identidade visual, layout e responsividade.
  • java.js: menu, cartões, validação do formulário e aviso de cookies.
  • chatbot.js: interface e lógica do chatbot.
  • minha-base-de-dados.json: perguntas, palavras-chave e respostas.
  • database.sql: script de criação do modelo relacional proposto.
